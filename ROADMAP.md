# 📖 O que é este Roadmap?

Este documento apresenta o planejamento oficial do projeto **Banco de Dados Relacionais**.

Aqui estão organizados todos os módulos previstos, seus capítulos, recursos didáticos e futuras expansões.

O objetivo é acompanhar a evolução do livro digital e servir como guia para o desenvolvimento do conteúdo.

---

# 🎯 Objetivos do projeto

Ao final deste projeto, o estudante deverá ser capaz de:

- compreender os fundamentos de Banco de Dados;
- analisar problemas reais;
- levantar requisitos;
- modelar soluções utilizando MER e DER;
- aplicar técnicas de normalização;
- implementar bancos de dados utilizando MySQL;
- escrever consultas SQL;
- interpretar consultas complexas;
- desenvolver projetos completos;
- pensar como um Analista de Sistemas.
