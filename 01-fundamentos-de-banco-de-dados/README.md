# 👋 Bem-vindo(a) ao primeiro módulo!

Antes de aprender SQL, criar tabelas ou desenvolver sistemas completos, precisamos entender **como as informações são armazenadas e utilizadas pelos computadores**.

Este módulo foi desenvolvido especialmente para quem está começando do zero.

Ao longo dos próximos capítulos, você descobrirá que praticamente **todos os sistemas modernos**, desde redes sociais até bancos digitais, dependem dos mesmos conceitos fundamentais que estudaremos aqui.

Mais do que decorar definições, nosso objetivo é fazer com que você compreenda **como um Banco de Dados funciona na prática**.

Ao final deste módulo, você terá construído uma base sólida para acompanhar todos os próximos conteúdos do curso.

---

# 🎯 Objetivos deste módulo

Ao concluir este módulo você será capaz de responder, com segurança, perguntas como:

- ✅ O que é um dado?
- ✅ O que é uma informação?
- ✅ Qual a diferença entre ambos?
- ✅ Como os dados geram conhecimento?
- ✅ O que significa persistência de dados?
- ✅ O que é um Banco de Dados?
- ✅ O que é um SGBD?
- ✅ Qual a diferença entre Banco de Dados e MySQL?
- ✅ Como um sistema salva informações?
- ✅ O que acontece quando clicamos em **"Cadastrar"** em um sistema?

Mais importante do que memorizar conceitos, você entenderá **por que eles existem** e **como se conectam**.

# 📚 Índice do módulo

## 📖 Capítulo 01 — Apresentação do módulo

Conheça os objetivos do curso, a importância dos Bancos de Dados e por que aprender seus fundamentos é essencial antes de escrever qualquer comando SQL.

➡️ **Arquivo:** `01-apresentacao-do-modulo.md`

---

## 📊 Capítulo 02 — Dado × Informação

Descubra por que um número isolado não possui significado e como o contexto transforma um simples dado em uma informação útil para pessoas e empresas.

➡️ **Arquivo:** `02-dado-x-informacao.md`

---

## 🧠 Capítulo 03 — Cadeia de Valor dos Dados

Entenda como empresas transformam milhões de registros em conhecimento capaz de orientar decisões estratégicas.

➡️ **Arquivo:** `03-cadeia-de-valor-dos-dados.md`

---

## 💾 Capítulo 04 — Persistência de Dados

Aprenda por que as informações desaparecem da memória RAM e como os Bancos de Dados garantem que elas permaneçam armazenadas mesmo após desligarmos o computador.

➡️ **Arquivo:** `04-persistencia-de-dados.md`

---

## 🗄️ Capítulo 05 — O que é um Banco de Dados?

Conheça a estrutura interna de um Banco de Dados Relacional, descubra o que são tabelas, registros, colunas e chaves, e entenda como essas estruturas organizam grandes volumes de informações.

➡️ **Arquivo:** `05-banco-de-dados.md`

---

## ⚙️ Capítulo 06 — O que é um SGBD?

Descubra o papel do Sistema Gerenciador de Banco de Dados, suas responsabilidades e por que ele é indispensável para qualquer aplicação moderna.

➡️ **Arquivo:** `06-sgbd.md`

---

## 🐬 Capítulo 07 — Ecossistema MySQL

Conheça os principais componentes do ambiente MySQL, como MySQL Server, MySQL Workbench e a linguagem SQL, entendendo a função de cada um dentro do desenvolvimento de sistemas.

➡️ **Arquivo:** `07-ecossistema-mysql.md`

---

## 🚀 Capítulo 08 — Como um sistema salva informações?

Acompanhe todo o caminho percorrido por um dado desde o clique do usuário em um botão até seu armazenamento definitivo no Banco de Dados.

➡️ **Arquivo:** `08-como-um-sistema-salva-informacoes.md`

---

## 🎓 Capítulo 09 — Revisão Geral

Revise todos os conceitos estudados por meio de mapas mentais, exercícios, desafios, glossário e um grande resumo integrando todos os assuntos do módulo.

➡️ **Arquivo:** `09-revisao-geral.md`
