# 👋 Seja muito bem-vindo(a)!

Se esta é a sua primeira experiência estudando Banco de Dados, seja muito bem-vindo.

Você está iniciando uma jornada extremamente importante dentro da área de Tecnologia da Informação.

Talvez você ainda não perceba isso...

Mas praticamente todos os sistemas que utilizamos diariamente dependem de Bancos de Dados.

Sempre que você:

- faz login em uma rede social;
- envia uma mensagem;
- realiza um PIX;
- compra um produto pela internet;
- assiste a um filme;
- solicita um carro por aplicativo;

há um Banco de Dados trabalhando silenciosamente nos bastidores.

E é justamente esse universo que começaremos a explorar.

---

# 🤔 Mas afinal...

## Por que estudar Banco de Dados?

Essa é uma excelente pergunta.

Muitas pessoas iniciam seus estudos acreditando que aprender Banco de Dados significa aprender comandos SQL.

Na realidade...

SQL representa apenas uma pequena parte desse universo.

Antes de criar tabelas...

Antes de escrever consultas...

Antes de aprender comandos...

Precisamos compreender **o problema que os Bancos de Dados foram criados para resolver.**

Essa será nossa missão ao longo deste módulo.

---

# 🧠 Como um profissional pensa?

Imagine que um cliente chega até uma empresa de desenvolvimento de software e faz o seguinte pedido:

> "Preciso de um sistema para controlar minha loja."

Um iniciante normalmente pensa:

> "Vamos começar criando tabelas."

Um profissional pensa diferente.

Ele começa fazendo perguntas como:

- Que tipo de loja?
- Quais informações precisam ser armazenadas?
- Quem utilizará o sistema?
- Quais processos precisam ser controlados?
- Quais problemas precisam ser resolvidos?

Perceba que, antes de existir qualquer Banco de Dados, existe um problema que precisa ser compreendido.

---

# 🌎 Banco de Dados está em todos os lugares

Talvez você nunca tenha parado para pensar nisso.

Mas praticamente tudo o que fazemos na internet depende de Bancos de Dados.

| Aplicação | Informações armazenadas |
|-----------|-------------------------|
| 📸 Instagram | Usuários, fotos, curtidas e comentários |
| 🎬 Netflix | Filmes, séries, perfis e histórico |
| 🎵 Spotify | Músicas, playlists e artistas |
| 🚗 Uber | Motoristas, passageiros e viagens |
| 🍔 iFood | Restaurantes, pedidos e entregas |
| 🛒 Mercado Livre | Produtos, vendedores e compras |
| 💳 Bancos | Contas, cartões, PIX e transações |
| 💬 WhatsApp | Conversas, grupos e contatos |

Embora sejam aplicações completamente diferentes...

Todas possuem algo em comum.

Elas precisam armazenar informações.

---

# 🧠 Analogia

Imagine uma biblioteca.

Agora imagine que todos os livros fossem colocados em uma enorme pilha no chão.

Encontrar apenas um livro seria extremamente difícil.

Agora imagine essa mesma biblioteca organizada.

Cada livro possui:

- uma categoria;
- uma estante;
- uma prateleira;
- uma posição específica.

Encontrar qualquer livro passa a levar apenas alguns segundos.

Um Banco de Dados funciona exatamente dessa maneira.

Ele organiza informações para que possam ser encontradas rapidamente.

---

# 🚀 Um pequeno desafio

Imagine que você decidiu abrir uma pequena loja.

Durante os primeiros dias tudo parece simples.

Você possui apenas cinco clientes.

Alguns produtos.

Poucas vendas.

Talvez até consiga controlar tudo utilizando um caderno ou uma planilha.

Agora imagine que, alguns meses depois, sua empresa possui:

- 👥 20.000 clientes;
- 📦 milhares de produtos;
- 💳 centenas de pagamentos por dia;
- 🚚 entregas para todo o país.

Como encontrar rapidamente:

- todos os pedidos de um cliente?
- o produto mais vendido?
- o faturamento do mês?
- os clientes inadimplentes?

É justamente para resolver problemas como esse que os Bancos de Dados existem.

---

# 💡 Curiosidade

Empresas como Google, Amazon, Netflix e Meta registram milhões de novos dados todos os dias.

Sem Bancos de Dados modernos seria praticamente impossível armazenar, organizar e consultar esse enorme volume de informações.

Na realidade...

SQL é apenas uma ferramenta.

Antes dela existem diversos conceitos fundamentais que todo profissional precisa dominar.

É exatamente essa base que construiremos neste módulo.

# 📚 Glossário

| Termo | Significado |
|--------|-------------|
| Banco de Dados | Estrutura utilizada para armazenar informações de maneira organizada. |
| SQL | Linguagem utilizada para consultar e manipular Bancos de Dados. |
| Sistema | Conjunto de componentes criado para resolver um problema específico. |
| Informação | Conjunto de dados organizados com significado. |
