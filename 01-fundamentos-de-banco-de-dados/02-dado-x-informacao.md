# 📖 Introdução

No capítulo anterior conhecemos o objetivo do módulo e entendemos por que os Bancos de Dados são fundamentais para praticamente todos os sistemas utilizados atualmente.

Agora chegou o momento de conhecer aquilo que representa a matéria-prima de qualquer Banco de Dados: **os dados**.

Pode parecer um conceito simples.

Afinal, ouvimos diariamente palavras como:

- dados móveis;
- dados bancários;
- banco de dados;
- análise de dados;
- ciência de dados.

Mas...

Você já parou para pensar no que realmente significa a palavra **dado**?

E mais importante...

Será que dado e informação significam exatamente a mesma coisa?

A resposta é **não**.

Embora muitas pessoas utilizem esses termos como sinônimos, existe uma diferença extremamente importante entre eles.

Compreender essa diferença é o primeiro passo para entender como sistemas armazenam informações e por que os Bancos de Dados existem.

---

# 🤔 Situação-problema

Imagine que você acabou de receber a seguinte mensagem no seu celular.

```text
38
```

O que significa esse número?

É sua idade?

É uma temperatura?

É uma nota?

É um preço?

É a quantidade de alunos em uma sala?

A verdade é que...

**Não temos como saber.**

O número "38" isoladamente não responde nenhuma dessas perguntas.

Agora imagine que alguém envie outra mensagem.

```text
Temperatura atual: 38°C
```

Instantaneamente tudo muda.

Agora você consegue interpretar aquele valor.

Você provavelmente concluirá que está fazendo muito calor.

Perceba que o número continua exatamente o mesmo.

O que mudou foi apenas uma coisa.

**O contexto.**

É justamente esse contexto que transforma um simples dado em uma informação.

---

# 🧠 O que é um dado?

Um **dado** pode ser definido como um valor bruto que representa um fato, uma característica ou um registro sobre algo.

Ele ainda não foi interpretado.

Não recebeu contexto.

Não responde perguntas.

Não auxilia diretamente na tomada de decisões.

Podemos imaginar o dado como a menor unidade de informação armazenável por um sistema.

Dados podem assumir diversas formas.

Por exemplo:

```text
Lucas

42

2026

15/08/2026

Azul

R$ 150,00

Santa Maria

Notebook
```

Todos esses elementos representam dados.

Individualmente, eles possuem pouco significado.

Não sabemos:

- quem é Lucas;
- por que existe o número 42;
- o que aconteceu em 2026;
- por que existe um notebook.

São apenas registros isolados.

---

# 📚 Definição formal

Podemos definir um dado da seguinte maneira.

> **Dado é um registro bruto de um fato, evento ou característica, ainda não interpretado e sem contexto suficiente para produzir significado.**

Essa definição é amplamente utilizada em áreas como Banco de Dados, Ciência de Dados, Inteligência Artificial e Sistemas de Informação.

---

# 📊 Características de um dado

Todo dado possui algumas características importantes.

Um dado geralmente é:

- objetivo;
- simples;
- armazenável;
- mensurável;
- registrável;
- isolado.

Observe alguns exemplos.

| Dado | Possui significado sozinho? |
|--------|----------------------------|
| 42 | ❌ Não |
| Lucas | ❌ Não |
| Azul | ❌ Não |
| 15/08/2026 | ❌ Não |
| R$ 200 | ❌ Não |

Todos eles dependem de contexto.

---

# 🧠 O que é uma informação?

Uma informação surge quando um ou mais dados recebem contexto, organização e interpretação.

A informação responde perguntas.

Ela reduz dúvidas.

Ela permite compreender uma situação.

Observe o exemplo.

Dados:

```text
Lucas

Notebook

R$ 3.500

15/08/2026
```

Informação:

```text
Lucas comprou um notebook por R$ 3.500,00 em 15/08/2026.
```

Agora tudo faz sentido.

Os mesmos dados foram organizados.

O resultado é uma informação.

---

# 📖 Definição formal

> **Informação é o resultado da organização, interpretação e contextualização de dados, tornando-os úteis para compreensão ou tomada de decisão.**

Essa é justamente a função de praticamente todos os sistemas existentes.

Eles coletam dados.

Organizam esses dados.

E apresentam informações ao usuário.

---

# ⚖️ Dado × Informação

A tabela abaixo resume as principais diferenças.

| Dado | Informação |
|-------|------------|
| Valor bruto | Valor interpretado |
| Isolado | Contextualizado |
| Sem significado completo | Possui significado |
| Não responde perguntas | Responde perguntas |
| Matéria-prima | Produto final do processamento |

Podemos resumir tudo em apenas uma frase.

> **Todo dado pode gerar uma informação, mas nem toda informação existe sem dados.**

---

# 🎨 Analogia 01 — As peças de um quebra-cabeça

Imagine um quebra-cabeça com mil peças.

Uma única peça representa um dado.

```text
🧩
```

Ela possui formato.

Possui cor.

Possui desenho.

Mas...

Você consegue descobrir qual imagem será formada olhando apenas para uma única peça?

Provavelmente não.

Agora imagine todas as peças organizadas.

```text
🧩 🧩 🧩 🧩 🧩
🧩 🧩 🧩 🧩 🧩
🧩 🧩 🧩 🧩 🧩

🏞️ Imagem completa
```

Agora existe significado.

A imagem completa representa a informação.

Os Bancos de Dados fazem exatamente isso.

Eles armazenam milhões de pequenas "peças" chamadas dados.

Quando consultados corretamente, esses dados revelam informações valiosas.

---

# 🎨 Analogia 02 — Ingredientes e receita

Imagine os seguintes ingredientes.

```text
🥚 Ovo

🌾 Farinha

🥛 Leite

🧈 Manteiga

🍫 Chocolate
```

Esses ingredientes representam dados.

Separadamente eles possuem utilidade limitada.

Agora imagine que um cozinheiro utilize esses ingredientes para preparar um bolo.

O bolo representa a informação.

Da mesma forma, um Banco de Dados organiza dados para produzir resultados úteis.

# 💭 Pare e pense

Se alguém lhe entregar apenas um CPF, você consegue saber quem é a pessoa?

Provavelmente não.

Mas...

Se esse CPF estiver associado a um nome, uma data de nascimento, um endereço e um histórico de compras, ele passa a representar uma grande quantidade de informações.

Percebe como o contexto transforma completamente o significado dos dados?
