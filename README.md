# 🎯 Objetivo deste material

O principal objetivo deste curso é ensinar Banco de Dados de uma maneira:

✅ Progressiva.  
✅ Didática.  
✅ Visual.  
✅ Prática.  
✅ Próxima da realidade profissional.  

A ideia não é fazer você decorar comandos.

A ideia é fazer você compreender:

> **Por que cada conceito existe e qual problema ele resolve.**

---

# 🧠 Nossa metodologia de aprendizado

Durante todo o material seguiremos uma sequência utilizada por profissionais da área.

## 1️⃣ Entender o problema

Antes de criar qualquer tabela, precisamos compreender:

- Qual informação precisa ser armazenada?
- Quem utiliza essa informação?
- Quais regras existem?
- Quais problemas precisam ser resolvidos?

---

## 2️⃣ Modelar a solução

Depois transformamos necessidades em estruturas.

Aprenderemos:

- Entidades;
- Atributos;
- Relacionamentos;
- Cardinalidades;
- Diagramas MER;
- Diagramas DER.

---

## 3️⃣ Construir o Banco de Dados

Somente depois partimos para o código.

Aprenderemos:

- Criação de bancos;
- Criação de tabelas;
- Relacionamentos;
- Chaves primárias;
- Chaves estrangeiras;
- Scripts SQL.

---

## 4️⃣ Resolver problemas reais

Por fim aplicaremos tudo através de:

- Estudos de caso;
- Exercícios;
- Desafios;
- Projetos completos.

## 💻 Módulo 05 — Scripts SQL

Agora chegou o momento de transformar modelos em código.

Neste módulo você aprenderá a implementar bancos reais utilizando MySQL.

Serão abordados:

### Linguagem SQL
- O que é SQL;
- Como o banco interpreta comandos;
- Organização dos comandos SQL.

### DDL — Data Definition Language

Criação e alteração da estrutura:

- CREATE DATABASE;
- CREATE TABLE;
- ALTER TABLE;
- DROP TABLE.


### DML — Data Manipulation Language

Manipulação dos dados:

- INSERT;
- UPDATE;
- DELETE.

### DQL — Data Query Language

Consulta dos dados:

- SELECT;
- WHERE;
- ORDER BY;
- GROUP BY;
- HAVING;
- JOINs.

# 📖 Como estudar este material?

A recomendação é simples:

**Não pule etapas.**

Banco de Dados possui uma construção progressiva.

A sequência ideal:

```text
01 - Fundamentos ➔ 02 - Requisitos ➔ 03 - Modelagem ➔ 04 - Normalização ➔ 05 - SQL ➔ 06 - Projetos
```

Cada etapa depende da anterior.

# ⭐ Nossa filosofia

Existe uma diferença entre:

> *"Aprender comandos"* e *"Entender tecnologia."*

Neste curso seguimos uma regra:

1. 🧠 Primeiro entender.
2. ✏️ Depois modelar.
3. 💻 Depois programar.

Porque bons profissionais não começam criando tabelas. Eles começam entendendo problemas.
